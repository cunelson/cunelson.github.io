Home Nest

A personal home-automation project

Home Nest connects a dashboard on my home network to my own Google Nest thermostat, so I can see the temperature and change the thermostat's settings from that page.

It isn't a public service. It is used only with my own Google account and my own thermostat, and there is nothing to sign up for.

Read the privacy policy for what Home Nest accesses and how that data is handled.

Questions: open an issue on GitHub.
