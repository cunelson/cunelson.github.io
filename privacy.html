Privacy policy

Home Nest · Effective November 17, 2026

Home Nest is a personal project that connects a dashboard on my home network to my own Google Nest thermostat. It is used only by me, with my own Google account.

What Home Nest accesses

With the permission granted when signing in with Google, Home Nest uses Google's Smart Device Management API to read the thermostat's current temperature, humidity, heating or cooling status, mode and target temperatures, and to change the mode and target temperatures when I ask it to. It does not access any other data in the Google account.

How the data is stored

The sign-in credential that Google issues is stored on a private computer on my home network. Thermostat readings are kept in memory for about a minute, to limit how often Google is asked, and are not saved or logged.

Sharing

No data is sold, shared or transferred to anyone. Nothing is used for advertising or analytics.

Google API Services User Data Policy

Home Nest's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Nest partner connections or from the third-party connections page of the Google account. Home Nest then can no longer read or change the thermostat.

Changes and contact

Any changes to this policy will be posted on this page. For questions, open an issue on GitHub.
